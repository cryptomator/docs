# New Features

**Cryptomator Hub 2.0.0** introduces the following new features:

- [User & Group Management](/hub/admin-guide/user-group-management) — Manage users, groups, roles, and permissions directly in Hub
- [Emergency Access](/hub/admin-guide/emergency-access) — Restore access to a vault in case of account loss or ownership issues

The [Admin Guide](admin-guide/quick-start.mdx) walks through both features in a worked example: see [Add Users and Groups](admin-guide/quick-start.mdx#add-users-and-groups) and [Enable Emergency Access](admin-guide/quick-start.mdx#enable-emergency-access).
