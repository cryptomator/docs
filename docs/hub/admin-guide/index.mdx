# Admin Guide

This guide is for administrators of a Cryptomator Hub instance. It covers users and groups, the connection to your identity provider, Emergency Access, the audit log, Web of Trust, and your license.

If your instance is fresh, start with the [Quick Start](quick-start.mdx). It walks you through your first day as an administrator. The other pages describe each area in detail.

:::note
If you also run the instance yourself, see the [Self-Hosting Guide](../self-hosting-guide/index.mdx) for deployment and maintenance.
:::
